## 四、成品 bgm_ready.wav 技术规格与验证

| 项 | 实测值 |
|---|---|
| 绝对路径 | `D:\BaiduSyncdisk\工作\PMMaster\openfilm\work\music\bgm_ready.wav` |
| 时长 | 00:00:58.00（精确 58 秒，可无损卡在 58s 时间线上） |
| 采样率 | 48000 Hz |
| 声道 | 2（stereo） |
| 编码 | pcm_s24le（24 bit） |
| 大小 | 16,704,244 字节 |
| 响度 | **−16.07 LUFS**（loudnorm 实测积分响度，目标 −16） |
| 真峰值 | −1.50 dBTP |
| 淡化 | 首 0.5 s 淡入、尾 0.5 s 淡出 —— RMS 实测：0–0.3 s 为 −30.6 dB（稳态 −19.0 dB），57.7–58 s 为 −26.8 dB |
| 取段 | Carefree 原曲 0:00–0:58（含自然引子），无循环、无拼接、未变速 |

生成命令（两遍 loudnorm，linear 线性增益，不做动态压缩）：

```
# 1) 裁 58s + 首尾各 0.5s 淡化 + 48kHz/立体声
ffmpeg -y -ss 0 -t 58 -i "src/Carefree.mp3" \
  -af "afade=t=in:st=0:d=0.5,afade=t=out:st=57.5:d=0.5" \
  -ac 2 -ar 48000 -c:a pcm_s24le _tmp/cf_faded_58.wav
# 2) 第一遍测量得到 measured_*，第二遍 linear=true 精确落到 -16 LUFS
ffmpeg -y -i _tmp/cf_faded_58.wav \
  -af "loudnorm=I=-16:TP=-1.5:LRA=11:measured_I=-20.22:measured_LRA=2.40:measured_TP=-5.63:measured_thresh=-30.22:offset=0.10:linear=true" \
  -ac 2 -ar 48000 -c:a pcm_s24le bgm_ready.wav
```

已复核：`ffmpeg -i bgm_ready.wav -f null -` 退出码 0，无错误；输出头为
`Duration: 00:00:58.00, 48000 Hz, stereo, pcm_s24le (24 bit)`。
