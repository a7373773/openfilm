## 二、主题构思：一场关于"呼吸与坚持"的徒步

用运动健康的角度把 3 分钟拆成 5 个章节，配 7 条字幕，让观众跟着走完一次完整的运动过程：

| 章节 | 内容 | 字幕 |
|---|---|---|
| 起步 | 出发，把城市留在身后 | 「出发 / 把城市的噪音留在身后」 |
| 林间 | 身体热起来 | 「身体先醒过来 / 心率加快，呼吸变深」→「林间穿行 / 找到自己的节奏」 |
| 爬升 | 最吃力的阶段 | 「最陡的一段 / 慢一点也没关系」→「补给时刻 / 水·盐分·一点耐心」 |
| 开阔 | 走出林子，视野打开 | 「山脊之上 / 云在脚下，风在耳边」 |
| 登顶 | 收束 | 「登顶 / 坚持的人，风景会自己找上来」 |

视觉包装（全部程序生成、可改字可换位置）：
- **标题卡**：0:00.7 起 5.6 秒，「运动·健康·山野 / 山野之间 / 一场关于呼吸与坚持的徒步」，配左下渐变遮罩保证可读
- **字幕条**：7 条左下角字幕（橙色竖条 + 主标题 + 副标题 + 半透明底板），各 5.2 秒
- **贴纸**：5 个（日出、心率波形、脚步、水滴、登顶旗），白色线性图标 + 半透明圆角底，各 3.4 秒
- **进度条**：底部一条橙色进度轨道 + 一个光点随片头走到片尾（"运动打卡"感）
- **结尾卡**：最后 5.8 秒「运动·健康·山野 / 今天流的汗，是明天的底气」+ 音乐署名

## 三、选镜头：去掉遮挡与重复

74 个片段（8 分 18 秒）→ 61 个镜头（2:57）。做法是两条独立证据链交叉验证：

1. **像素分析**（每 0.5 秒一帧，共 993 帧）：锐度、双尺度拉普拉斯比、边缘密度、熵、亮度、饱和度、帧间差，按每个镜头自身分位做相对阈值；
2. **CLIP 画面内容识别**：逐帧判「人物/背影/大远景/遮挡/糊/雾化」，并给出每个镜头"遮挡秒段"。

然后用三刀切：

- **重复镜头**：只找出 **1 组真重复** —— C1827 与 C1828 是同一静止机位的两次拍摄（帧级 1:1 对应，dHash 4~5、直方图余弦 0.94），弃短的 C1827。
  另外核查过你怀疑的 C1897/C1898（时长都 17.02s 是巧合，帧级完全对不上，运动特征相反：一个快摇一个慢摇）和 C1843/C1844（亮度 47 vs 144，完全不同的画面）——**都不是重复，都保留**。
- **整段废片（7 个）**：C1905 / C1906 / C1907 / C1908 / C1909（镜头被手/衣物挡住或装包过程，边缘密度仅 0.05~0.13、锐度 15~191，几乎无细节）；C1826、C1862（背包/衣物怼镜头，遮挡帧占比 60%/93%）。
- **遮挡秒段**：按 CLIP 给出的每镜头遮挡区间，把保留窗口整体挪开或缩短，保证每个镜头取的都是干净段落。

保留 61 个镜头里 A 档（清晰）23 个、B 档 22 个、C 档 16 个（偏暗/偏软，只给 2~3 秒做节奏过渡）。

## 四、转场：11 处，不夸张也不缺席

61 个剪辑点里只有 **11 处有转场（18%）**，其余 50 处是硬切：

| 类型 | 数量 | 用在哪 |
|---|---|---|
| 交叉淡化 fade 0.7s | 4 | 章节之间（起步→林间→爬升→开阔→登顶），最稳、最不抢戏 |
| 叠化 dissolve 0.45s | 3 | 章节内画面质量最高的几个剪辑点 |
| 平滑左推 smoothleft 0.45s | 3 | 连续推进类镜头之间，制造"往前走"的方向感 |
| 圆形展开 circleopen 0.45s | 1 | 进入登顶章节前的最后一下，唯一一处稍微"有戏"的转场 |
| 硬切 | 50 | 其余全部 |

原则：**章节切换用淡入淡出，章内偶尔叠化/推拉，绝不连用**，所以不会显得花哨。

## 五、滤镜调色

没有买 LUT，用 ffmpeg 做的一套"户外通透"调色（参数可直接照搬）：

```
每镜头曝光归一  eq:gamma（按该镜头平均亮度反推，目标 0.42，gamma 限幅 0.80~1.95）+ 轻微 brightness 补偿
              —— 这段素材前 1/3 是清晨林间，平均亮度只有 25~90，靠这一步统一提亮才不会"一段亮一段黑"
              （实测：最暗的 C1848 从 21 提到 110 上下，和后面明亮的镜头接得上）
高光滚降        curves: 0→0.008, 0.25→0.252, 0.50→0.520, 0.80→0.812, 1.0→0.930
对比/饱和       contrast 1.04 / saturation 1.04 / gamma 1.01
自然饱和度      vibrance 0.10（提灰部的彩，让林子的绿和天空更透）
冷暖分割        shadows B +0.020 / R -0.008（阴影偏冷，林间更"清爽"）
              highlights R +0.016 / B -0.010（高光偏暖，阳光洒下来更"有温度"）
```

想换风格：更浓的夏日感→vibrance 提到 0.18；更"高级灰"电影感→contrast 1.10、saturation 0.98、阴影再压青一点；清晨雾感→高光滚降更狠一点、整体 gamma 0.96。
