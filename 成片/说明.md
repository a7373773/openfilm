## 二、怎么把"糊的/遮挡的"剔除掉的

素材里没有全黑的镜头，问题主要是两类：
1. **虚焦/运动糊**（相机被手或身体挡住、或刚举起还没对上焦）；
2. **镜头朝下对着路面/地面/衣服**（画面清晰，但没有风景）。

单看"清晰度"识别不出第 2 类（路面纹理很锐），所以做了两条独立证据链交叉验证：

- **像素分析**：24 个文件逐秒（1 帧/秒，共 2603 帧）计算锐度、双尺度拉普拉斯比（区分"真虚焦"和"大面积天空"）、边缘密度、熵、饱和度、颜色丰富度、帧间差等，按每个文件自身的 P90 做相对阈值 → 得到 28 段 / 239 秒黑名单。
- **画面内容识别**：本地跑 CLIP 零样本分类（ViT-B/32），把每帧判成"风景 / 手挡镜头 / 衣物遮挡 / 近景地面 / 糊"并打场景标签，同样逐秒打标。

剪辑时一个镜头要整段都满足「不在黑名单 + 锐度 ≥ 300 + CLIP 判定为风景且非近距离遮挡」才会被采用。
被判为"整条基本没有风景"的文件直接不进备选池：REC-0019、REC-0023、REC-0024、REC-0025、REC-0026、REC-0027（朝下拍地面）；REC-0002（手+衣物遮挡）。
最终用到的 10 个文件：REC-0007、0012、0013、0014、0015、0016、0017、0018、0020、0021、0022。

## 三、滤镜（调色）

没有买 LUT，也没用付费滤镜——用 ffmpeg 做了套**免费可复现**的风景向调色，参数如下（可直接在剪映/达芬奇里照着手调）：

```
锐化/缩放     4K → 1080p Lanczos 高质量降采样
自动曝光对齐  每镜头按自身亮度分位做黑白点归一（强度 0.55，只作用于亮度，不动色相，避免把夕阳调成灰）
高光滚降      curves: 0→0.010, 0.25→0.255, 0.50→0.525, 0.80→0.800, 1.0→0.920
              （把过曝的天空压回来，原片里最高有 24% 像素纯白，处理后为 0）
对比/饱和     contrast 1.02 / saturation 1.02
自然饱和度    vibrance 0.08（只提灰部的彩，蓝天、雾气更透，已经鲜艳的不过饱和）
冷暖分割      shadows R -0.012 / B +0.028；highlights R +0.025 / B -0.012
              （阴影偏青蓝、高光偏暖，是这个"阳光通透"感觉的来源）
```
整体效果：天空不再一片死白，绿色和蓝色更透，暗部微青、阳光处微暖，饱和度约 +20%（按实测，不夸张、不像开了"鲜艳"滤镜）。

想换风格随时说：
- 更干净通透 → 减 curves 的压高光、vibrance 提到 0.15
- 更暖夕阳感 → highlights R +0.05 / B -0.03，色温整体 +300K
- 更电影感 → 加对比 1.08、暗部再压青一点、加轻微暗角

## 五、剪辑结构

- **节奏**：全片按 96 BPM 的拍点排布，镜头长度都是 2 拍(1.25s)/3 拍/4 拍(2.5s)/6 拍 的整数倍，剪辑点落在小节线上，所以卡点感明显但不机械。
- **开场**：6 秒大远景推入，画面从黑场淡入；结尾 5 秒收回并淡出到黑。
- **转场**：统一 0.5 秒交叉淡化（scenic 混剪最稳的转场，不用花哨转场）。
- **慢动作**：4 个镜头用 0.5× 慢放（60fps 源 → 30fps 输出，慢放依然顺滑），放在镜头运动较快的段落，压住手持抖动、也让风景更有呼吸感；其余镜头原速，避免整片"拖"起来。
- **时长**：57.5 秒，留了 2.5 秒余量，任何平台都不会卡 60 秒。
