## 0. 摘要

- 全片 **74 镜头 / 993 帧 / 约 496 秒**（与素材 8 分 18 秒相符）。
- **人物几乎无处不在**：97.9% 的帧判为“画面里有人”（p_person≥0.5），80.4% 的帧判为“跟拍背影”（p_back≥0.5）。这批素材本质是**跟着一个人走的跟拍素材**，所以“有人”不是筛选条件，**“背影 + 风景并存”才是运动感主力**。
- **纯空镜很少**：只有 3 个镜头人物占比 <0.5（C1827 / C1828 / C1829，合计约 9 秒；且 C1827/C1828 是林间偏暗、C1829 偏糊）。真正的开阔风景要靠山顶那几个镜头，但其中多数是雾化/低细节（见 3.3），清晰可用的是 C1894 / C1882 / C1895。
- **“对着地面/脚下”基本没有**：view 组的 ground_feet 只命中 **1/993 帧**，独立物理规则（无天空 + 低绿色 + 上暗下亮）也只命中 3.3%，且这些帧多为林冠/岩壁误判。**这类废镜头不是本批素材的主要问题。**
- **真正的废镜头是三类**：① 手/衣物糊镜头（p_blocked≥0.5，84 帧 = 8.5%）；② 背包/后背怼满画面（back_close，120 帧 = 12.1%）；③ 整体糊（客观 lapvar <0.006）。逐镜头清单见 3.1。
- **结尾大远景要小心**：CLIP 大远景分最高的 C1905 / C1908 / C1907 / C1883 客观细节极低（lapvar 0.0002~0.0030、下半画面 botLap≈0.001），是**雾化/接近空白**的画面。综合“开阔 + 有实体细节”后推荐 **C1894S03 / C1882S03 / C1895S03**（lapvar 0.011~0.014、botLap 0.026~0.034）；C1905S03 可当“朦胧远山”情绪镜头。详见 3.3。

## 1. 方法

### 1.1 标签体系（6 组 / 24 类 / 53 条提示词）

| 组 | 类 | 用途 |
|---|---|---|
| presence | one / multi / none | p_person = 1−P(none)，p_people = P(multi) |
| **view** | back_far / back_close / ahead_path / ground_feet / vista_wide / facing | **核心组**：6 种互斥取景，直接回答“跟拍背影 / 背包怼镜头 / 对地 / 大远景” |
| occlusion | blocked / clear | p_blocked = 手 / 衣物 / 包遮住镜头 |
| quality | sharp / blur / dark | p_blurry = 虚焦 + 欠曝 |
| landscape | wide / subject / unclear | p_landscape = 山景 / 林间 / 远景占画面 |
| scene | trail / forest / mountain / summit / sky / water / other | 主场景 |
每类用 2~3 条描述句做**提示词集成**（嵌入平均再归一化），每组**独立 softmax**，避免“人物”与“遮挡”互相稀释。

### 1.2 迭代过程（为什么改了三版）

| 版本 | 问题 | 处理 |
|---|---|---|
| v1 | presence 与 occlusion 混在一组，p_closeup 有 55% 帧 ≥0.5，与物理规则（仅 14.8%）严重不符 | 拆成独立小组 |
| v2 | 加 framing 组后 back 类吃掉 78% 概率，p_closeup 塌到 0.04 | 改成 6 类 view 组，让“背包怼镜头 / 对地 / 空径 / 大远景 / 正面”互为竞争项 |
| v3（最终） | — | view 分布：back_far 71.7%、back_close 12.1%、vista_wide 11.0%、facing 3.0%、ahead_path 2.1%、ground_feet 0.1% |

该分布与素材性质（跟拍徒步 vlog）吻合，且 ground_feet 几乎不触发、与物理规则只命中 3.3% 相互印证 —— v1 的“对地”判定是假阳性。

### 1.3 校验

| 校验 | 结果 |
|---|---|
| 内部一致性：p_person vs 另一组独立措辞的 p_human | 相关 **+0.67** |
| p_landscape vs 独立措辞的 p_wide2 | 相关 **+0.70** |
| p_wide_vista vs 天空占比 skyfrac | 相关 **+0.49** |
| p_blurry vs 客观锐度 lapvar / 边缘密度 edge | **−0.56 / −0.65** |
| p_blocked vs 肤色占比 skin / 垂直梯度 vertGrad | **+0.49 / −0.51** |
| p_ground vs 物理“纯对地”规则 | 弱（+0.16）→ 该类别在本批素材几乎不存在，不用于筛选 |

**注意**：<code>p_blurry</code> 是相对量。这批帧客观 lapvar 中位数仅 0.017（1080p→480px + 走路抖动），p_blurry 均值 0.66 说明整体偏软，**不要用绝对值筛片，用镜头间相对比较 + lapvar**。

## 5. 使用建议

1. **开场 / 中段运动感**：用 3.2 节运动分高的镜头（C1884 / C1886 / C1899 / C1895 / C1898 / C1877 等），它们“背影 + 风景 + 少遮挡”三者兼备；单镜头 2~19 秒，可直接按 3~5 秒截取 3.2 节给出的现成秒段。
2. **结尾**：用 **C1894S03（6.5s）/ C1882S03（6.5s）/ C1895S03（5.5s）** —— 开阔且画面有实体细节（lapvar 0.011~0.014、botLap 0.026~0.034）；想要“朦胧远山”氛围可用 C1905S03（13s，低反差发灰）；**C1907 / C1908 / C1883 接近空白，不建议做结尾**。
3. **剔除**：3.1 节的废镜头。特别提醒 **C1862S03**：人物/风景分看着高，但 93% 的帧 p_blocked≥0.5、背包怼满画面（back_close 0.73），实际基本不可用，别被高分误导。
4. **过渡**：C1895 / C1894 / C1881 的 vista 帧可做 2 秒空镜过渡。
5. 遮挡秒段精度 0.5 秒，全部在 <code>per_clip.json</code> 的 <code>blocked_ranges</code>；可用背影段在 <code>motion_ranges</code>；远景段在 <code>vista_ranges</code>。

## 6. 局限

1. 团队里没人能直接看图，结论来自 CLIP + 客观像素统计两条独立证据链，方向一致（见 1.3），但不是人眼确认。带 ⚠ 的镜头建议抽 1~2 帧肉眼复核。
2. **p_person 几乎饱和（97.9%）**，不能用来排序“有多有人”，只能用来找“几乎没人”的少数镜头；动作感排序请用 3.2 的运动分。
3. **p_ground 在本批素材几乎不触发（0.1%）**，与物理规则（3.3% 且多为林冠误判）一致 → 这批素材没有明显“对地/对脚”镜头。若剪辑师看到某段确实在拍地，以人眼为准。
4. “背包怼镜头”（back_close）可靠度中等：它与“近距离背影”语义接近，12% 的帧处于边界，可能有 1~2 帧误判。
5. p_blurry 是相对量，1080p→480px 的帧客观偏软（lapvar 中位 0.017），不要当绝对清晰度标准。
6. 0.5 秒抽帧，遮挡/可用段的边界精度为 ±0.5 秒。
