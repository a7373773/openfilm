## 2. 方法与阈值

每帧（480px 宽）指标：luma 亮度均值、lumastd 亮度标准差、darkfrac(亮度<28 占比)、brightfrac(>230 占比)、sat 饱和度、colorful(Hasler-Süsstrunk 颜色丰富度)、sharp(Laplacian 方差)、grad / edgefrac(Sobel 均值 / 边缘像素占比)、entropy(64 段灰度熵)、uniform(距中值<12 的像素占比)、flatfrac(12 分块中无细节块占比)、warmfrac(暖色/肤色块占比)、fineratio(480 与 240 两个尺度拉普拉斯方差之比，衡量高频细节是否真的存在：真虚焦时该值明显偏低)、diff(与上一帧平均绝对差)。

阈值（细节类均相对该文件自身 P90，避免不同场景互相误伤）：

| 类别 | 条件 |
|---|---|
| BLACK 极暗 | luma<35 或 darkfrac>0.70 |
| WHITE 过曝 | luma>240 或 brightfrac>0.80 |
| BLOCK 无细节/疑似遮挡 | edgefrac<0.15xP90 且 sharp<0.15xP90（既无边缘也无锐度） |
| BLUR 低锐度/虚焦 | sharp<0.25xP90 且 edgefrac<0.50xP90 且 fineratio<0.16 且 lumastd>=32（有反差但无细节） |
| FLATS 单色板/天空 | uniform>0.45 或 lumastd<25 |
| 突变点 | diff>4x文件中位 且 >25 |

连续被标记的秒合并为区间（间隔 <=2 秒合并）；长度 >=5s 为高置信，2-4s 中，1s 低。

## 7. 数据文件

- metrics.json - 每文件每秒全部指标（原始数据，可直接画曲线）
- segments.json - 判定结果（问题区间 / 可用区间 / 突变点 / 质量分）

- frames/REC-XXXX/sec_NNNN.jpg - 每秒 1 帧（480px 宽，sec_0001 = t=0s）
- sheets/REC-XXXX.jpg - 联系图 10 列 x N 行，每格 192px，格内左上角黄字 = 该格秒数
- sheets/REC-XXXX.txt - 行/列 到 秒 的映射表
