# 剪辑流程与规则 · v1

> 这个文件是**固定流程**，不是建议。每次开新片按顺序走，最后一步必须过闸（PASS）才能出片。
> 参数在 `pipeline/rules.json`，改规则改那里，不要在脚本里硬编码。

---

## 第 0 步 · 先定三件事（动素材之前）

1. **主题**：这条片子讲什么、给谁看、多长（默认 2–3 分钟）。
2. **画幅**：主题 + **素材主体** 一起决定。主题是横屏、素材主体也是横屏 → 全片 1920×1080 横屏，中途不改。
3. **情绪**：决定配乐与调色的方向（轻快温馨 / 安静克制 / 热闹）。

> 画幅一旦定下就是**硬约束**：后面所有镜头都必须符合，不符合的素材直接不进候选池。

## 第 1 步 · 建索引（自动）

```
python pipeline/01_index.py "素材/某次拍摄" work/<slug>
```

每个文件输出：时长、分辨率、**旋转角**、画幅分类、逐 0.5 秒锐度/亮度、人脸数量与占比、颜色直方图签名、质量分、以及被拒原因。

**被剔除的（不进候选池）**：
- 带 90° / 270° 旋转标记（竖着拍的）
- 分辨率不是目标画幅的
- 锐度低于阈值（虚焦 / 糊）
- 亮度 > 235（白到发灰）或 < 65（欠曝）

> 这条是这次踩过的坑：两条竖着拍的素材被拉伸成横屏，人是变形的。现在第 1 步就拦掉。

## 第 2 步 · 去重（自动聚类 + 择优）

脚本按颜色直方图把同场景的镜头聚成簇，**每个簇只留评分最高的一条**。

硬规则：
| 情况 | 处理 |
|---|---|
| 同一个素材文件出现两次 | **禁止**（0 容忍） |
| 近重复簇（簇内 ≤3 条，几乎同机位） | **只能留 1 条** |
| 场景簇（簇内 ≥4 条，同一片场地） | 最多 2 条，且必须**景别/人物/时刻明显不同**，间隔 ≥10 秒 |

> "精彩片段"不靠人挑开头：每个候选都用**滑窗寻优**——在整条素材里找锐度最高、亮度最正、没有过曝的 3–7 秒作为入点。

## 第 3 步 · 配乐（情绪先于名气）

```
python pipeline/05_music.py work/music/src <成片秒数>
```

规则（写在 rules.json，练习 **calm / 舒缓纯音乐** 档）：

- **很轻的纯音乐**——独奏钢琴、木吉他为主；不要电子、不要重鼓、不要史诗弦乐
- **不要太快**：BPM 62–92（75 上下最舒展）；BPM 变了，镜头时长要重新贴拍子（`pipeline/16_retime.py~BT~）
- **不要太跳跃**：音符密度 onset < 12 个/秒
- **不要太吵**：能量平稳（小节 RMS p90−p10 ≤ 7 dB），低频占比 < 0.15，频谱重心 < 1600 Hz
- **时长覆盖成片**：不够就让同曲 A/B 段循环或从曲尾开始取（曲尾会自然收束，结尾更干净）

场景对照：
| 场景 | 首选音色 |
|---|---|
| 田园 / 自然 / 田野 | 钢琴独奏、木吉他 |
| 人物 / 温馨时刻 | 钢琴、弦乐拨奏 |
| 街市 / 热闹段落 | 轻打击乐 + 木吉他 |
| 收尾 / 情绪落点 | 单乐器或留白 |

## 第 4 步 · 结构 + 节奏

- 按**真实时间线**排段落（出发 → 探索 → 高光 → 收尾），不按好看程度乱跳。
- 所有镜头时长 = **一拍（0.625s @96BPM）的整数倍**，切点落在拍子上。
- 首镜头淡入、末镜头淡出到黑。

## 第 5 步 · 转场（跟着画面走，不炫技）

| 转场 | 什么时候用 |
|---|---|
| 交叉淡化 0.6s | **默认**，占 65% 以上 |
| 左滑 / 右滑 | 前后镜头的运动方向一致（摇镜、走位） |
| 上滑 | 从地面/稻穗向上摇的时候 |
| 白场淡入 | 光线或场景层级**明显变化**（正午 → 日落） |
| 圆形展开 | 段落切换、进入"好玩"的部分 |
| 溶解 | 时间跳跃（隔了几十分钟） |

硬约束：**方向性转场不超过总切点的 35%**，且必须与镜头运动方向一致，否则会"打架"。

## 第 6 步 · 调色（真实优先，参数有预算）

```
python pipeline/04_grade.py     # 打印当前 look 与预算校验
```

只做四件事：**逐镜头曝光对齐 → 高光滚降 → 轻微暖度推进 → 轻锐化**。

预算（超了就是失真，脚本会报 violations）：

| 参数 | 上限 | 说明 |
|---|---|---|
| 饱和度 | 1.10 | 超过就假 |
| 自然饱和度 | 0.16 | 只提灰部彩度 |
| 对比度 | 1.06 | 不要压成电影感 |
| 高光暖度 | 0.05 | 阴影最多偏青 0.02 |
| LUT | **禁用** | 风格化滤镜一律不用 |

**暖度随时间推进**：前半段保持素材本身的色温，后半段（日落）才逐步加暖——跟真实光线对得上，而不是全片套一层橙色。

## 第 7 步 · 过闸（必须 PASS）

```
python pipeline/03_check.py work/<slug>/edl.json
```

检查项（有 FAIL 就不许出片）：

| 关卡 | FAIL 条件 |
|---|---|
| ASPECT / SIZE | 出现非横屏或非目标分辨率 |
| DUP_FILE | 同一素材用了两次 |
| DUP_TIGHT | 近重复簇用了超过 1 条 |
| BEAT | 镜头时长不在拍点网格上 |
| TRANSITIONS | 方向性转场超过 35%，或用了不在白名单里的转场 |
| DURATION | 片长不在 120–210 秒 |
| GRADE | 调色预算缺失或被突破 |

警告项（可以带病出片，但要能解释）：松散场景簇重复、同簇镜头间隔 <10 秒、锐度偏低、配乐响度越界。

## 目录

```
pipeline/
  rules.json     规则与阈值（唯一事实源）
  common.py      共用：探测、抽帧、统计、质量分、聚类
  01_index.py    建索引 + 画幅闸 + 聚类
  02_pick.py     一键初剪（每簇一条、拍点对齐、转场配额）
  03_check.py    出片闸门（PASS / FAIL）
  04_grade.py    调色参数生成 + 预算校验
  05_music.py    配乐分析选曲（BPM / 能量起伏 / 频谱重心 / 低频占比）
```
